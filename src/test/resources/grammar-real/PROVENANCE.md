# Real third-party grammars used by the import tests

Each file is an unmodified copy of a public grammar pinned to a commit; the expected types in `GrammarTypeInferenceImportTests` come from each
language's own type inference (Langium: the `ast.ts` generated by langium-cli 4.4.0; Xtext: its documented inference rules), never from HYDRA.
